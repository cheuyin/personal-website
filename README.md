Terminal-themed personal site. [Astro](https://astro.build) static build.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

```bash
astro dev --background   # background dev server
astro dev stop
```

## Layout

```text
src/pages/           routes
src/content/writing/ Markdown posts → /writing/[slug]
src/data/site.ts     editable copy & project links
src/styles/global.css
```
